# AdSense Global Audit Skill

## Master Directives

1. **Safety Analysis**: Analyze layout configurations to prevent accidental clicks.
2. **Content Checks**: Ensure content provides value and adheres to AdSense program policies.
3. **Dynamic Updates**: Automatically update auditing rules based on the contents of `adsense-updates.txt`.
4. **Implementation Validation**: Verify correct integration of ad tags and responsive ad units.
